NOTES / RULES THAT APPLY THROUGHOUT
  - float64 throughout, including snapshots (dev 7.2)
  - Snapshots stream to parquet, never accumulate in memory (dev 7.3)
  - Exposures are not persisted; per-tick counts + 1% sample only
  - Registry stays a sorted list; never branch on exact float equality
  - Statistical reproducibility across seeds is the promise, not bitwise
  - Always sweep multiple seeds; report distributions, not points
